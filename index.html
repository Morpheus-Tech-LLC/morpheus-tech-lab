Memory limit
64 - 16384

How much memory the engine may use for cells. Your browser caps each tab's memory, whatever your computer has, and a page can't find out that cap in advance. If the browser refuses memory, the run stops cleanly and keeps its last generation; if the system closes the tab first, which is likelier with little memory, the run is lost. This limit stops the run before that. Try about 1024 on a typical laptop and 2048 to 4096 on a strong desktop; 512 is cautious, for phones and small machines.
